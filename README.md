# Starting the server: 

### Navigate to Backend

cd src/backend

--------------------------------------------------

### Install Dependencies

- npm install
- npm install typescript
- add a .env file in the backend folder with JWT_SECRET="Your-own-random-string"

add a .env file in the backend folder with JWT_SECRET="Your-own-random-string"
--------------------------------------------------

### Run the Development Server

npm run dev

--------------------------------------------------

### Data Storage

Users are stored in:
users.json

This file acts as a simple mock database.

--------------------------------------------------

Notes

- This backend is for prototype/demo purposes only
- No authentication or security is implemented
- Passwords are stored in plain text (do NOT use in production)
